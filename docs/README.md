# Documentation Index

- `adr/` — Architecture decision records. For anyone changing domain rules, output paths, or numeric constraints.
- `agents/` — Agent-facing process docs: domain model, issue tracker, triage labels. For agentic workers and maintainers.
- `specs/` — Feature and rewrite specifications. For contributors implementing or reviewing large changes.
- `tickets/` — Local ticket files (GitHub Issues are disabled). For anyone picking up or tracking planned work.
