# Domain owns product display rules

The clean-architecture layering left several pure product rules stranded in infrastructure and application adapters: EXIF display normalization (Nikon `ℤ`/Roman numerals, Sony `α`, vendor washing, shutter formatting), the 13-vendor built-in logo matching, the bundled-font alias catalog, and the preview quality of 70 (defined in two places). We decided the domain layer owns every deterministic product rule — the `MetadataReader` port returns raw extracted values and the application layer normalizes them via domain functions; logo matching and the font alias catalog move into the domain; preview quality becomes a single domain constant consumed by both the use case and the renderer. Adapters keep only I/O mechanics (tag extraction, decoding, shaping, compositing, publishing). A future metadata source (XMP, ffprobe) then inherits identical display behavior instead of re-implementing it — and port contracts must state explicitly whether they exchange raw or normalized values.
